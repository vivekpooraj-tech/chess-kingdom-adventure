# Wikimedia Classic piece set — attribution

These chess-piece SVGs are derived from the **Cburnett** standard diagram set on
[Wikimedia Commons](https://commons.wikimedia.org/wiki/Category:SVG_chess_pieces)
(`Chess_*t45.svg` files — light/dark pieces on a transparent square).

## Author

**Cburnett** (Colin M. L. Burnett), with later edits by TomFryers, Antonsusi,
Smasongarrison, and others as recorded on each file’s Commons history page.
