SESSION LOOP
================================================================================

Every session (15-25 min) follows:
teach -> guided_board -> puzzle_drill -> apply (bot_match OR parent_mode OR pass_and_play) -> recap -> checkpoint

Pass puzzle_drill if >= passCriteria (e.g. 2/3 correct). Fail -> remedial (one easier puzzle) -> retry. Never hard-block forever.

Step types to implement:
- teach: Ollie text + optional FEN demo
- guided_board: ChessBoard, legal moves, hints fade after wrong tries
- puzzle_drill: 2-3 puzzles with verified solutions
- bot_match: weak bot or movesRequired like existing mini_match
- parent_mode: parent instruction panel + child board same device
- pass_and_play: two-player same tablet
- exam, ceremony, recap

Ollie copy (embed in content, keep short):
- Intro: Today we learn {skill}. You've got this.
- Mistake: That's okay. Even I did that when I was learning.
- Win: You didn't get lucky. You saw the move.
- Fork Festival: Today you learn the sneakiest trick in chess.
- Pre-graduation: Tomorrow you play for real. I'm proud of you.
- Graduation: You're not learning chess anymore. You're a chess player.

Scope Ollie to today's skill. Text-first OK.
